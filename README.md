# Deutsch Offline · 德语全课程

9册：A1、A2、B1.1—B1.4、B2.1、B2.2、C1.1。140单元、700课、1,166段合成音频（含140段词汇朗读）。

公开学习页无需登录。Safari 分享 → 添加到主屏幕。在“离线与记录”按册保存，等待完成后可断网学习。首次访问需联网；安装到主屏幕不等于已经下载所有音频。浏览器/系统可能回收缓存。

学习进度与作答保存在当前设备，不自动云同步。可导出/导入 JSON 备份。仓库中无个人学习记录、密钥或账户信息。

每单元保留五课：词汇与搭配、语法详解、听力口语、阅读写作、文化翻译；包括答案、附录及册末测评。原始可编辑课程位于 source/，原教材 PDF 位于 pdf/。

Windows EXE、Android APK 下载见 Releases。EXE 内置Python运行时和全部资源；首次启动解压到 D:\副业\德语学习\tmp\runtime，课程在默认浏览器显示，本地服务仅监听127.0.0.1。学习记录保存在EXE旁的Deutsch-data目录。APK为个人签名，适用于Android 6.0及以上；课程内置，不要求联网权限。未使用商业Windows代码签名证书。

说明：长文包含双语辅导扩展材料；内部小分册不是单独的官方CEFR等级。语音为Conrad男声及Katja女声合成，不是真人录音。此课程不代表官方考试认证。

C1.1新增20单元100课、400项词汇、40个语法概念和161段音频；每单元五课均完整保留。PDF包含全部课文、测评、答案和音频入口。
